Welcome! Let's set you up.

This extension automatically exports your LinkedIn saved posts and saves them as CSV files — no passwords stored, runs in your existing session.

1
Make sure you're signed in to LinkedIn
The exporter uses your existing LinkedIn session. If you're not signed in when a run fires, you'll get a notification to sign in first.
2
Choose your export schedule
The exporter runs silently in the background on this schedule.
Every 12h
Every 24h
⚗ 15 min
3
Define batch size
How many posts to export per run. Each run picks up from where the last one left off.
10 ~30s
25 ~1–2 min
50 ~2–3 min
100 ~5–6 min
Estimated run time: ~1–2 min
4
Choose a sub-folder name (optional)
Chrome extensions can only save files inside your Downloads folder. Type a sub-folder name to keep things organised, or leave blank to save directly to Downloads.
Downloads /
Leave blank to save to Downloads directly.
5
Generate AI titles (optional)
After export, an AI model reads each post and generates a concise title. Requires an API key from Anthropic or OpenAI — your key never leaves this device.
